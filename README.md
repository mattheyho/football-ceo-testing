# Football CEO — iPhone-friendly refactored build

All project files deliberately live in the repository root so they can be uploaded through GitHub on iPhone.

Upload every file in this folder to the root of the GitHub repository.

Files:
- index.html
- styles.css
- database.js
- game.js
- state.js
- transfers.js
- simulation.js
- staff.js
- commercial.js
- stakeholders.js
- ui.js

The current working gameplay remains in game.js. The smaller module files are placeholders that we will progressively populate as development continues.
