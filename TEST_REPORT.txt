Important current limitation:
Possession, pressing, verticality and tactical flexibility are stored and shown to the user,
but the current player database does not yet contain enough style attributes for those values
to influence target selection properly. They are deliberately available for the next tactical/
player-profile layer rather than being faked against unrelated attributes.

Villa goalkeeper expected behaviour:
With a strong starting GK plus one credible senior backup, the manager should no longer request
another established backup purely because a second backup slot is absent. If no suitable young
high-potential goalkeeper is already present, a manager with sufficient youth/depth preference
may instead generate a PROSPECT request. This is the intended Martínez/Bizot fix.
