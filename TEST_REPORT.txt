Integration notes:
- Calendar logic lives in game.js, so no new script/module is required.
- transfers.js references calendar helpers at runtime; game.js is loaded after transfers.js,
  but these calls occur after page initialization, so the existing script order is compatible.
- state.week deliberately remains a match-count concept for form, appearances and performance
  thresholds. It no longer drives transfer windows or time-based cooldowns.
- Transfer bid/counter negotiations themselves remain immediate for now. The daily engine is
  ready for multi-day negotiation responses later, but v0.15.0 does not intentionally change
  that interaction yet.
- Cups/Europe are not scheduled yet, so fixture congestion is a controlled PL-only approximation.
