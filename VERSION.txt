Football CEO v0.20.0 — Mobile UI Foundation

UI FOUNDATION
- Portrait-first Home screen rebuilt around the daily CEO loop.
- Home now prioritises club/date, league position, transfer budget, SCR, next fixture, form, stakeholders and urgent inbox.
- Old mobile dashboard menu grid removed.
- Persistent bottom navigation: Home / Squad / Transfers / Inbox / More.
- Continue Day is now persistent above the mobile navigation and remains available across management screens.
- Continue/nav controls automatically hide while a modal is open.
- Dedicated Inbox screen replaces the expanding dashboard inbox.
- More menu contains fixtures, table, finances, staff, facilities, matchday/pricing and career controls.
- Existing desktop tab navigation remains available above 760px as a compatibility layout.

STAKEHOLDERS
- Home stakeholder cards are compact and clickable.
- Tapping Fans, Owners, Players, Manager or Sponsors opens a detailed relationship panel.
- Detail panel shows current score/mood, explanation, all current drivers, up to 10 recent relationship changes and active threshold/risk information.
- The detail panel contains an internal foundation for future CEO interaction options without adding unfinished gameplay actions yet.

COMPATIBILITY
- Simulation systems, transfers, development, SCR, saves and league logic are unchanged from the cumulative v0.19.3 gameplay build.
- Existing DOM IDs used by gameplay systems are preserved wherever required.
- Existing save format unchanged.
- PWA cache: football-ceo-v0.20.0-pwa-1.
