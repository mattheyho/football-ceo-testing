Football CEO v0.15.2 — Manager Profiles

- Removed random manager formation assignment.
- Added persistent real-world-inspired profiles for all 20 starting Premier League managers.
- Added preferred and alternative formations.
- Added 0-100 manager attributes:
  possession, pressing, verticality, flexibility,
  recruitment aggression, youth trust and squad-depth demand.
- Preferred formation now drives manager XI selection and squad-depth analysis.
- Recruitment aggression affects request appetite.
- Youth trust enables development-prospect requests.
- Depth demand changes senior-cover expectations.
- Goalkeeper logic now treats one credible senior backup as sufficient.
- Managers can request a young prospect instead of an unnecessary established third goalkeeper.
- Current manager profile is visible on the Staff screen.
- Manager candidates show formation/pressing/youth/flexibility information.
- Existing v0.15.1 saves migrate automatically: legacy random manager formations are overwritten by the profile.
